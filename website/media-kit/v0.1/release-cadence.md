# 发布节奏与运营内容 v0.1

> 来源：plan §6.7。素材发布必须与本表阶段一致：不允许在 Devnet 阶段使用 Testnet/MVP 的能力话术。

## 阶段表

| 阶段 | 对外内容 | 资金范围 | 退出条件 | 状态 |
|---|---|---|---|---|
| Devnet | 开源代码、开发者 quickstart、模拟牌局 | 仅 PLAY | devnet smoke test 和文档可复现 | **当前** |
| Testnet | faucet、explorer、proof portal、漏洞赏金 | PLAY；REAL 关闭 | P0/P1 安全项关闭、事故演练通过 | 未开始 |
| MVP | 受控 PLAY + 小规模 REAL 内测、透明度报告 | REAL 白名单/限额 | 账实对账、提现 SLA、人工 runbook | 未开始 |
| BFT preview | validator 招募、checkpoint、DA、ForceInclude 演示 | REAL 仍受限 | 4–7 validator 容错和审查演练 | 未开始 |
| Mainnet candidate | 第三方审计、公开 release、迁移手册 | 按地区和合规策略 | 全部主网门槛和回滚演练 | 未开始 |

## 内容节奏

- 每周一次开发周报（变更、测试、风险）→ 模板 [templates/weekly-update.md](templates/weekly-update.md)
- 每两周一次社区演示 → 模板 [templates/biweekly-demo.md](templates/biweekly-demo.md)
- 每月一次透明度报告 → 模板 [templates/monthly-transparency.md](templates/monthly-transparency.md)
- 内容日历 → 模板 [templates/content-calendar.md](templates/content-calendar.md)

## 事故纪律

事故期间停止营销内容，优先发布：影响范围、用户操作建议、修复时间线；恢复后出复盘。状态页与 `#announcements` 是唯一事实源。
