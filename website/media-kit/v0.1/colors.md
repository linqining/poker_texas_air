# 颜色规范 v0.1.1（账簿 Ledger）

变量与官网样式表 `website/assets/css/main.css` 的 `:root` / `html[data-ground="night"]` 完全同源；
任何一侧修改必须同步（本目录另附机器可读的 `brand.css`，由 `main.css` 生成）。

## 两套底面

| | 默认 | 可切 |
|---|---|---|
| 底面 | **纸白 paper** | **夜场 night** |
| 选择器 | `:root` | `html[data-ground="night"]` |
| 触发 | 首帧内联脚本按 `prefers-color-scheme` 决定 | 右上角切换按钮，选择存 `localStorage.zchain-ground` |

改版前站点只有夜场一套，且 `:root` 就是夜场。v0.1.1 把纸白提为默认，
**夜场 14 个基色 token 一个都没改** —— 所以这次改版是叠加，不是替换：切到夜场≈改版前的站。

## 资产与语义色

每个语义色配一个 `-w` 浅底，用于状态丸（`.st` / `.ch`）与横幅。
纸白的 `-w` 是实色，夜场的 `-w` 是 alpha 叠加 —— 算对比度时必须先合成再比，
`check_a11y.py` 已按此实现。

| 变量 | 纸白 | 夜场 | 用途 |
|---|---|---|---|
| `--felt` | `#0b6b45` | `#37e39c` | 春翡翠：链接、主行动、成功态 |
| `--felt-deep` / `--felt-dim` / `--felt-w` | `#085234` / `#a8c8b6` / `#e6efe8` | `#1a8a58` / `#14593a` / `rgba(55,227,156,.11)` | 毡布深/描边/浅底 |
| `--play` | `#15507f` | `#66c4ff` | PLAY（天蓝）：测试/娱乐筹码标识色 |
| `--play-deep` / `--play-w` | `#a9c0d6` / `#e5ecf3` | `#14486f` / `rgba(102,196,255,.11)` | PLAY 描边/浅底 |
| `--real` | `#7d5308` | `#ffc75a` | REAL（暖金）：托管真实资产映射标识色 |
| `--real-deep` / `--real-w` | `#d8bd85` / `#f6ebd4` | `#7a5410` / `rgba(255,199,90,.11)` | REAL 描边/浅底 |
| `--real-orange` | `#8a5a12` | `#e2933b` | REAL 辅助（图表） |

| `--amb` | `#825510` | `#ffd166` | 警示横幅（非错误、非托管） |
| `--amb-deep` / `--amb-w` | `#dcc796` / `#f6eeda` | `rgba(255,209,102,.35)` / `rgba(255,209,102,.10)` | 警示描边/浅底 |
| `--nav-active-text` | `#f5f2ea` | `#05130c` | 主色按钮/导航上的反差文字 |

规则：任何涉及 REAL 的区块必须同时出现托管提示；金色不得用于非 REAL 的营销强调。
`--amb` 与 `--real` 在纸白底上都是棕金，靠**用法**区分（amb 只出现在警示横幅与描边，
real 只出现在资产语义），不得混用。

## 对比度（实测，`python3 website/tools/check_a11y.py`）

品牌线 **≥ 5.2:1**（高于 WCAG AA 正文 4.5）。半透明 `-w` 底先合成实色再算。

| 底面 | 最低项 | 比值 |
|---|---|---|
| 纸白 paper | `danger on danger-w` | 5.52 |
| 夜场 night | `muted-2 on surface-2` | 5.29 |

纸白其余关键项：`text on bg` 16.61、`text on surface` 18.27、`muted on bg` 8.16、
`felt on bg` 5.86、`play on bg` 7.55、`real on bg` 6.03、`amb on bg` 5.77、
`nav-active-text on felt` 5.86。

> **v0.1.1 的两处修正**：`--muted-2` 纸白 `#666256 → #5f5b50`、`--amb` 纸白 `#8a5a12 → #825510`。
> 原值分别只有 5.08 与 5.11（`muted-2 on code-bg`、`amb on amb-w`），低于品牌线。
> 之所以一直没被发现，是因为旧版 `check_a11y.py` 把调色板**硬编码**在脚本里（且只有夜场），
> 无论 CSS 怎么改它都报"all rules passed"。现已改为从 `main.css` 解析两套底逐一双算。

## 形状与阴影

账簿只有两种圆角，且**没有"浮起"**：

| 变量 | 值 | 说明 |
|---|---|---|
| `--radius-sm` | `2px` | 状态丸、标签、切换按钮 |
| `--radius` | `3px` | 卡片、输入框、表格 |
| `--radius-lg` | `6px` | 弹窗 |
| `--radius-pill` | `2px` | 名字保留但值是方角（原为胶囊，改版后废除曲线） |
| `--shadow-card` / `--shadow-pop` | `0 1px 0 rgba(20,19,15,.04)` | 只有一条 1px 的纸边投影；夜场下为 `none` |
| `--glow-felt` | `none` | 发光废除，变量保留防脏引用 |

## 动效（v0.1.1 大幅收缩）

v3 的入场/常驻/交互动效在账簿方向全部取消，只保留：

- 表格行 hover 换底色；卡片 hover 换描边色。
- 无障碍：`prefers-reduced-motion: reduce` 下连这两条也关闭。
- 明确不做（沿用 v0.1 的踩坑结论）：依赖滚动进入视口的显现动画 —— 实测在整页截图/打印等
  非滚动渲染路径下会把内容停在 `opacity: 0`（2026-09-13 验收踩坑后移除）。
- 新增不做：无位移/缩放类动画。账簿的层级靠**规线、左规线 3px、印章、等宽数字**表达，不靠动效。
