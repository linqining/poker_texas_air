# 内容日历模板

> 粒度：周。事故周整体置空，仅保留事故通报行。

```markdown
# 内容日历 <月份>

| 周 | 周报（每周） | 演示（双周） | 透明度（每月） | 其他内容 | 风险检查 |
|---|---|---|---|---|---|
| W1 | #<n> <日期> | — | — | <如：技术博文 / 版本公告> | 禁用词扫描通过？水印/版本一致？ |
| W2 | #<n> | 演示 #<m> <主题> | — |  | 数字与 fact-sheet 一致？ |
| W3 | #<n> | — | — | <社区 AMA>（可选） |  |
| W4 | #<n> | 演示 #<m> | 透明度报告 #<k> | 月度回顾 | 报告签名与验签命令就绪？ |

## 发布前检查（每个内容项）
- [ ] 禁用词扫描 0 命中（website/tools/scan_banned_words.py）
- [ ] 环境与版本水印（如 PLAY / devnet / v1.3）
- [ ] 性能数字附口径；未测量写"未测量"
- [ ] REAL 相关表述带托管提示
- [ ] 不与事故窗口重叠（事故期间停营销）
```
